# R&M Legacy Business Solutions

Website for R&M Legacy Business Solutions (formerly The Coding Phoenix): websites, administrative support and grant help for churches and small businesses.

Plain HTML and CSS, deployed to GitHub Pages by the workflow in `.github/workflows`.

- `index.html`: home
- `churches.html`: church websites and packages
- `services.html`: all services and prices
- `about.html`: about Melissa
- `request.html`: request form (sends through Formspree)
- `contact.html`: old link, forwards to `request.html`
- `css/site.css`: all styles (colors are at the top)
- `js/site.js`: mobile menu and form sending
- `images/site/`: optimized images used by the pages
